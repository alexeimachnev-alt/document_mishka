# Генератор документов МИШКА

1. Распакуйте файлы в пустую папку.
2. В файле `.env` впишите токен от BotFather.
3. Положите в эту же папку файл шаблона доверенности (имя файла указано в `generator.py`).
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите бота локально `python bot.py` или отправьте файлы на GitHub для Render.
