# Генератор документов МИШКА (Сертификаты и Доверенности)

1. Распакуйте архив в пустую папку (это будет ваш новый репозиторий).
2. Замените `YOUR_BOT_TOKEN_HERE` в файле `.env` на токен вашего бота от BotFather.
3. Поместите в эту папку файлы шаблонов и шрифтов:
    * `cert_template.jpg`
    * `МИШКА Доверенность м2 с печатями и подписью заполнять в середине-4.pdf`
    * `arial.ttf`
    * `arialbd.ttf`
    * `times.ttf`
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите бота локально для проверки: `python bot.py`
6. Залейте папку на GitHub и подключите к Render как Web Service (Render автоматически увидит requirements.txt и запустит aiohttp сервер для поддержания работы 24/7).
